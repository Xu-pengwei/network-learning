# Windows 10 加入域与域账户登录验证实验报告

## 一、实验名称

Windows 10 加入 Windows Server 2022 域，并使用域账户登录验证。

## 二、实验目的

1. 了解 Windows 域环境的基本组成和作用。
2. 掌握 Windows 10 客户端加入域的方法。
3. 掌握客户端 DNS 地址的配置方法。
4. 学会使用域账户 `LAB\student` 登录 Windows 10。
5. 学会使用命令检查计算机网络信息和当前登录身份。
6. 理解 DNS 服务、域控制器和客户端之间的关系。

## 三、实验环境

| 项目 | 实验配置 |
|---|---|
| 虚拟化软件 | VMware Workstation |
| 域控制器 | Windows Server 2022 |
| 客户端 | Windows 10 |
| 域登录前缀 | LAB |

## 四、实验原理

Windows 域是一种集中管理计算机和用户账户的网络环境。域控制器负责保存域中的用户、计算机和安全策略等信息。

Windows 10 加入域后，可以使用域控制器中创建的账户登录。管理员也可以在服务器上集中管理域用户和客户端计算机。

在域环境中，DNS 服务非常重要。Windows 10 客户端需要通过 DNS 找到域控制器，因此客户端的首选 DNS 服务器一般要设置为域控制器的 IP 地址。如果 DNS 地址设置错误，客户端可能出现无法找到域、无法加入域或无法使用域账户登录等问题。

## 五、网络环境检查

在开始加入域之前，需要确认 Windows Server 2022 和 Windows 10 虚拟机能够正常通信。

### 1. 检查虚拟机网络模式

打开 VMware，检查 Windows Server 2022 和 Windows 10 的网络适配器设置，确保两台虚拟机使用相同的虚拟网络模式。

例如，两台虚拟机都使用：

- 仅主机模式；
- NAT 模式；
- 或同一个自定义虚拟网络。

### 2. 检查服务器网络信息

在 Windows Server 2022 中打开命令提示符，执行：

```cmd
ipconfig /all
```

记录服务器的 IPv4 地址、子网掩码和 DNS 地址。

### 3. 检查客户端网络信息

在 Windows 10 中打开命令提示符，执行：

```cmd
ipconfig /all
```

检查客户端是否获得了正确的 IPv4 地址，并确认客户端与服务器处于同一网络。

### 4. 测试网络连通性

在 Windows 10 中执行：

```cmd
ping 服务器IP地址
```

例如：

```cmd
ping 192.168.10.10
```

如果能够收到服务器返回的数据，说明 Windows 10 与 Windows Server 2022 之间的网络连接正常。

如果无法连通，需要检查：

- 两台虚拟机是否使用相同的网络模式；
- IP 地址和子网掩码是否正确；
- Windows 防火墙是否阻止 ICMP；
- 虚拟网卡是否已经启用。

## 六、配置Windows 10客户端DNS

### 1. 打开网络适配器设置

在 Windows 10 中依次打开：

```text
控制面板
→ 网络和 Internet
→ 网络和共享中心
→ 更改适配器设置
```

右键单击正在使用的网络适配器，选择“属性”。

### 2. 配置IPv4地址

选择“Internet 协议版本 4（TCP/IPv4）”，然后点击“属性”。

根据实验环境填写：

```text
IP地址：请填写客户端实际IP
子网掩码：请填写实际子网掩码
默认网关：根据实验环境填写
首选DNS服务器：填写Windows Server 2022的IP地址
```

客户端的首选 DNS 服务器必须指向域控制器，不建议直接填写公共 DNS 地址。

### 3. 检查DNS设置

完成设置后，打开命令提示符并执行：

```cmd
ipconfig /all
```

检查“DNS 服务器”一项是否显示 Windows Server 2022 的 IP 地址。

### 4. 测试域名解析

执行：

```cmd
nslookup 完整域名
```

也可以尝试：

```cmd
ping 完整域名
```

如果可以正确解析出服务器的 IP 地址，说明客户端 DNS 配置正常。

## 七、将Windows 10加入域

### 1. 打开系统属性

在 Windows 10 桌面右键单击“此电脑”，选择“属性”，然后进入高级系统设置。

也可以按下：

```text
Win + R
```

输入：

```text
sysdm.cpl
```

点击“确定”，打开系统属性。

### 2. 修改计算机所属关系

进入“计算机名”选项卡，点击“更改”。

在“隶属于”区域选择“域”，然后输入完整域名。

例如：

```text
lab.local
```

这里应填写完整的 DNS 域名，具体内容以服务器中的实际域名为准。

### 3. 输入域管理员凭据

系统提示输入账户和密码时，输入具有将计算机加入域权限的账户。

例如：

```text
LAB\Administrator
```

输入正确密码后继续操作。

### 4. 确认加入域

如果网络、DNS和账户信息正确，系统会显示类似下面的提示：

```text
欢迎加入 lab.local 域
```

点击“确定”，按照提示重新启动 Windows 10。

## 八、使用域账户登录

Windows 10 重新启动后，在登录界面选择“其他用户”。

用户名输入：

```text
LAB\student
```

然后输入 `student` 域账户对应的密码。

如果能够正常进入 Windows 10 桌面，说明域账户登录成功。

需要注意：

- `LAB\student` 是域账户；
- `.\student` 或“计算机名\student”是本地账户；
- 上课验证域环境时，应使用 `LAB\student` 登录；
- 管理服务器时，应使用具有管理员权限的账户。

## 九、验证域账户身份

登录成功后，打开命令提示符，依次运行以下命令。

### 1. 查看当前登录账户

```cmd
whoami
```

正常情况下应显示：

```text
lab\student
```

这说明当前登录的是 LAB 域中的 `student` 账户。

### 2. 查看当前域

```cmd
echo %userdomain%
```

正常情况下应显示：

```text
LAB
```

### 3. 查看当前用户名

```cmd
echo %username%
```

正常情况下应显示：

```text
student
```

### 4. 查看完整网络配置

```cmd
ipconfig /all
```

重点检查：

- Windows 10 的 IPv4 地址；
- 子网掩码；
- 默认网关；
- DNS 服务器地址；
- DNS 后缀。

### 5. 查看计算机和域信息

```cmd
systeminfo
```

在结果中查看“域”一项，确认计算机已经加入正确的域。

也可以执行：

```cmd
whoami /user
```

查看当前域账户的名称和安全标识符。

## 十、服务器端验证

除了在 Windows 10 客户端验证，还可以在 Windows Server 2022 上检查客户端和域账户。

### 1. 检查域用户

在 Windows Server 2022 中打开：

```text
服务器管理器
→ 工具
→ Active Directory 用户和计算机
```

进入对应的用户容器，确认 `student` 账户存在并处于启用状态。

### 2. 检查客户端计算机

在“Active Directory 用户和计算机”中打开“Computers”容器，检查是否出现已经加入域的 Windows 10 计算机。

如果能够看到客户端计算机名称，说明客户端计算机账户已经成功创建到域中。

### 3. 检查DNS记录

打开：

```text
服务器管理器
→ 工具
→ DNS
```

进入正向查找区域，检查是否存在域控制器和客户端对应的主机记录。

## 十一、实验结果

完成网络和 DNS 配置后，Windows 10 客户端可以正常连接 Windows Server 2022，并成功加入域。

重新启动 Windows 10 后，可以使用 `LAB\student` 域账户登录系统。

执行 `whoami` 命令后，系统显示：

```text
lab\student
```

执行 `echo %userdomain%` 后，系统显示：

```text
LAB
```

在 Windows Server 2022 的“Active Directory 用户和计算机”中，可以查看 `student` 用户和已经加入域的 Windows 10 计算机。

以上结果说明 Windows 10 已经成功加入域，域账户登录与身份验证均正常。

## 十二、常见问题及解决方法

### 1. 提示找不到域

可能原因：

- Windows 10 的首选 DNS 地址填写错误；
- DNS 服务器没有正常运行；
- 客户端与服务器不在同一网络；
- 输入的完整域名错误。

解决方法：

- 将客户端首选 DNS 设置为域控制器的 IP 地址；
- 使用 `ping` 检查网络；
- 使用 `nslookup` 检查域名解析；
- 核对服务器中的完整域名。

### 2. 客户端可以ping服务器，但无法加入域

可能是 DNS 配置错误。能够通过 IP 地址访问服务器，不代表能够通过域名找到域控制器。

可以运行：

```cmd
ipconfig /flushdns
```

然后重新执行：

```cmd
nslookup 完整域名
```

确认域名能够正确解析。

### 3. 域账户无法登录

需要检查：

- `student` 用户是否已经创建；
- 用户账户是否处于启用状态；
- 密码是否正确；
- 登录名是否使用 `LAB\student`；
- Windows 10 是否已经成功加入域；
- Windows 10 是否能够连接域控制器。

### 4. 登录界面只显示本地用户

点击“其他用户”，手动输入：

```text
LAB\student
```

不要只输入 `student`，否则系统可能尝试使用本地账户登录。

### 5. 加入域后仍然显示工作组

重新启动 Windows 10，然后打开系统属性检查域信息。如果仍然显示工作组，需要重新检查加入域的操作是否成功。

通过本次实验，我完成了 Windows 10 客户端网络配置、DNS 设置、加入域、域账户登录和身份验证等操作。
