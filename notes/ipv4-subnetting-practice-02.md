# IPv4 子网划分进阶练习：/28 与 CIDR 反推

学习日期：2026-11-13

学习时长：约 30～45 分钟  
来源：本次课程中的实际答题与逐题批改。

## 一、今日学习目标

1. 熟悉 /28 的主机位、地址块大小和可用主机数。
2. 根据 IP 地址判断所在子网，并计算网络地址、广播地址和可用范围。
3. 根据所需主机数量反推合适的 CIDR 前缀。
4. 理解将 /24 划分为多个 /26 子网时的子网数量和单个子网容量。

## 二、核心计算规则

```text
主机位数量 = 32 - CIDR 前缀长度
单个子网总地址数 = 2^主机位数量
单个子网可用主机数 = 总地址数 - 2
子网数量 = 2^(新前缀长度 - 原前缀长度)
```

网络地址是子网区间的第一个地址，广播地址是区间的最后一个地址；普通主机使用两者之间的地址。

注意区分：
- 单个子网的地址数和可用主机数；
- 一个较大的网络划分后，所有子网的数量与总地址数；
- 子网数量与单个子网可容纳的主机数量。

## 三、/28 子网计算练习

/28 的计算：

```text
主机位 = 32 - 28 = 4
总地址数 = 2^4 = 16
可用主机数 = 16 - 2 = 14
块大小 = 16
```

最后一个八位组的区间按 16 递增：

```text
0～15
16～31
32～47

64～79

```

### 练习 1：192.168.168.45/28

用户最初回答：
- 网络地址：192.168.168.33
- 广播地址：192.168.168.46
- 地址数与可用主机数：将 16 和 14 的含义写反

纠正过程：45 落在 32～47 区间，.33 和 .46 是可用主机范围的起止地址，而不是网络地址和广播地址。

正确结果：

| 项目 | 正确结果 |
|---|---|
| 网络地址 | 192.168.168.32 |
| 第一个可用地址 | 192.168.168.33 |
| 最后一个可用地址 | 192.168.168.46 |
| 广播地址 | 192.168.168.47 |
| 总地址数 | 16 |
| 可用主机数 | 14 |

概念巩固时，用户曾将“.33 不能作为网络地址”的原因误选为“它是广播地址”。正确理解是：.33 是该子网的第一个可用主机地址。

### 练习 2：192.168.168.130/28

用户独立回答：
- 网络地址：192.168.168.128
- 广播地址：192.168.168.143
- 第一个可用主机地址：192.168.168.129

以上答案全部正确。完整可用范围为 192.168.168.129～192.168.168.142，可用主机数为 14。

## 四、根据主机数量反推 CIDR

选择前缀时，先计算满足需求所需的最少主机位，再检查可用主机数是否足够。

### 练习 3：需要容纳 50 台电脑

用户选择 /26，并正确计算主机位为 6；但最初把单个子网容量与整个 /24 划分后的总容量混在一起。

正确计算：

```text
主机位 = 32 - 26 = 6
单个 /26 总地址数 = 2^6 = 64
单个 /26 可用主机数 = 64 - 2 = 62
```

因此选择 /26，可以容纳 50 台电脑。

补充：一个 /24 划分成 4 个 /26，每个子网有 64 个总地址、62 个可用主机地址；整个 /24 共 256 个地址，4 个子网合计 248 个可用主机地址。不能把 248 写成单个 /26 的可用主机数。

### 练习 4：需要容纳 100 台电脑

用户选择 /25，计算过程全部正确：

```text
主机位 = 32 - 25 = 7
总地址数 = 2^7 = 128
可用主机数 = 128 - 2 = 126
```

126 大于 100，因此 /25 满足需求。

## 五、综合练习：/24 划分为 /26

题目：将 192.168.168.0/24 划分为 /26。

用户回答：
- 子网数量：6
- 每个子网总地址数：64
- 每个子网可用主机数：62
- 第三个子网网络地址：192.168.168.128
- 第三个子网广播地址：192.168.168.191

批改结果：后四项（每个子网总地址数、可用主机数、第三个子网网络地址和广播地址）正确；子网数量应为 4，而不是 6。

正确推导：

```text
借用的子网位数 = 26 - 24 = 2
子网数量 = 2^2 = 4
每个 /26 总地址数 = 2^(32 - 26) = 64
每个 /26 可用主机数 = 64 - 2 = 62
```

四个子网：

| 子网序号 | 网络地址 | 广播地址 |
|---|---|---|
| 第一个 | 192.168.168.0 | 192.168.168.63 |
| 第二个 | 192.168.168.64 | 192.168.168.127 |
| 第三个 | 192.168.168.128 | 192.168.168.191 |
| 第四个 | 192.168.168.192 | 192.168.168.255 |

## 六、今日易错点与纠正

1. **混淆网络地址、广播地址和可用地址。** 网络地址是区间起点，广播地址是区间终点，中间才是可用主机地址。
2. **混淆总地址数与可用主机数。** /28 有 16 个总地址、14 个可用主机地址；/26 有 64 个总地址、62 个可用主机地址。
3. **混淆单个子网与整个网络的容量。** 单个 /26 有 62 个可用主机地址；/24 划分成 4 个 /26 后，合计有 248 个可用主机地址。
4. **子网数量公式需要继续巩固。** /24 划分为 /26，借用 2 位，因此子网数量为 2² = 4，不是 6。
