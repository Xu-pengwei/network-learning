# Windows Server 2022 DNS 实验记录

## 一、实验目的

- 了解 DNS 的基本作用
- 掌握 DNS 服务器的基础配置方法
- 学会使用客户端验证域名解析结果

## 二、实验环境

- 服务器：Windows Server 2022
- 客户端：Windows 10
- 运行环境：VMware 虚拟机
- 域名：请填写自己的实验域名
- DNS 服务器地址：请填写自己的服务器 IP

## 三、实验步骤

### 1. 配置服务器网络

为 Windows Server 2022 设置固定 IP 地址，并将首选 DNS 服务器设置为服务器自身的 IP 地址。

### 2. 安装 DNS 服务

打开“服务器管理器”，选择“添加角色和功能”，安装“DNS 服务器”角色。

### 3. 创建正向查找区域

打开 DNS 管理器，新建正向查找区域，并按照实验要求填写区域名称。

### 4. 添加主机记录

在正向查找区域中添加主机（A）记录，将域名映射到对应的 IP 地址。

### 5. 配置客户端

将 Windows 10 客户端的首选 DNS 服务器设置为 Windows Server 2022 的 IP 地址。

## 四、验证方法

在 Windows 10 客户端打开命令提示符，运行：

```cmd
ipconfig /all
nslookup 域名
ping 域名
```

如果 `nslookup` 能返回正确的 IP 地址，并且 `ping` 可以解析出对应地址，说明 DNS 配置成功。

## 五、实验结果

Windows 10 客户端能够通过域名查询到正确的 IP 地址，说明 DNS 服务器可以正常完成域名解析。

## 六、遇到的问题

- 客户端无法解析域名时，首先检查客户端的首选 DNS 地址。
- 检查服务器与客户端是否处于同一网络。
- 检查正向查找区域中的主机记录是否正确。
- 修改记录后，可运行以下命令清除客户端 DNS 缓存：

```cmd
ipconfig /flushdns
```

## 七、实验总结

通过本次实验，我了解了 DNS 将域名解析为 IP 地址的过程，并掌握了 DNS 服务安装、正向查找区域创建、主机记录添加和客户端验证的方法。
