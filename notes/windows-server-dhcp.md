1. 了解 DHCP 服务的基本作用。
2. 掌握 Windows Server 2022 中 DHCP 服务器的安装方法。
3. 掌握 DHCP 地址池、网关和 DNS 等参数的配置方法。
4. 使用 Windows 10 客户端验证自动获取 IP 地址的功能。

## 三、DHCP 简介

DHCP 的全称是 Dynamic Host Configuration Protocol，即动态主机配置协议。

DHCP 服务器可以自动向客户端分配以下网络参数：

- IP 地址
- 子网掩码
- 默认网关
- DNS 服务器地址
- 地址租约时间

使用 DHCP 可以减少手动配置 IP 地址的工作量，并降低地址填写错误或地址冲突的概率。

## 四、实验步骤

### 1. 安装 DHCP 服务器角色

1. 打开“服务器管理器”。
2. 点击“管理”。
3. 选择“添加角色和功能”。
4. 选择“基于角色或基于功能的安装”。
5. 选择当前 Windows Server 2022 服务器。
6. 勾选“DHCP 服务器”。
7. 添加所需功能并开始安装。
8. 安装完成后进行 DHCP 安装后配置。

### 2. 完成 DHCP 授权

如果服务器已经加入 Active Directory 域，需要使用有权限的域管理员账户对 DHCP 服务器进行授权。

授权完成后，DHCP 服务器才可以在域环境中正常分配 IP 地址。

### 3. 创建 IPv4 作用域

1. 打开“服务器管理器”。
2. 点击“工具”。
3. 打开“DHCP”管理控制台。
4. 展开服务器名称。
5. 右键单击“IPv4”。
6. 选择“新建作用域”。
7. 设置作用域名称，例如：

```text
LAB-Network
```

### 4. 配置地址池

本次实验的实际作用域配置如下：

| 配置项目 | 实际参数 |
|---|---|
| 地址池起始地址 | `192.168.168.1` |
| 地址池结束地址 | `192.168.168.254` |
| 排除范围一 | `192.168.168.1 - 192.168.168.10` |
| 排除范围二 | `192.168.168.254` |
| 实际可分配范围 | `192.168.168.11 - 192.168.168.253` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | `192.168.168.2` |
| DHCP 服务器 | `192.168.168.10` |
| DNS 服务器 | `192.168.168.10` |
| DNS 域名 | `lab.test` |
| 租约期限 | 8 天 |

服务器固定地址 `192.168.168.10` 位于排除范围内，因此不会被重复分配给客户端。Windows 10 的 `192.168.168.168` 地址已设置为保留地址，并在 DHCP 控制台中显示为活动状态。

### 5. 激活作用域

完成地址池、网关和 DNS 参数配置后，选择立即激活作用域。

在 DHCP 管理控制台中检查 IPv4 作用域，确认作用域图标和服务状态正常。

### 6. 配置 Windows 10 客户端

打开 Windows 10 客户端的网络适配器设置，将 IPv4 配置修改为：

- 自动获得 IP 地址
- 自动获得 DNS 服务器地址

### 7. 重新获取 IP 地址

在 Windows 10 中以管理员身份打开命令提示符，依次执行：

```cmd
ipconfig /release
ipconfig /renew
ipconfig /all
```

通过 `ipconfig /all` 查看客户端是否获得了 DHCP 服务器分配的 IP 地址、子网掩码、默认网关和 DNS 地址。

## 五、验证内容

实验完成后需要验证以下内容：

## 八、常见问题

### 1. 客户端无法获取 IP 地址

可能原因：

- DHCP 作用域没有激活。
- DHCP 服务没有启动。
- 服务器与客户端不在同一虚拟网络。
- VMware 自带 DHCP 与 Windows Server DHCP 发生冲突。
- DHCP 地址池配置错误。
- 防火墙或网络适配器设置存在问题。

### 2. 客户端获得 `169.254.x.x` 地址

这通常表示客户端没有成功联系 DHCP 服务器，需要检查服务器状态、网络连接和作用域配置。

### 3. 客户端获得了 IP，但无法解析域名

需要检查 DHCP 作用域中的 DNS 服务器地址是否正确，以及 DNS 服务是否正常运行。
