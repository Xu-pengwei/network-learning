## 学习节奏

- 每次学习控制在 30～45 分钟。
- 每次尽量完成“理论、操作、验证、练习、总结”五个环节；纯理论练习应如实标注，不虚构实验验证。
- 每周至少整理两篇真实学习记录。
- 实验状态只根据实际操作结果更新。
- 每完成一个阶段，在 README 和对应学习文档中记录成果。
