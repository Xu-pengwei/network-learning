## 近期学习记录与安排

2026-11-12 已完成 [11 - IPv4 地址与子网划分基础](notes/ip-subnetting-basics.md) 的首轮练习：通过 Ubuntu 验证 192.168.168.128/24、直连网络和广播地址，掌握主机位、块大小、网络地址、广播地址及可用主机数的计算，并完成 /26、/27 区间判断。

2026-11-13 已完成 [IPv4 子网划分进阶练习：/28 与 CIDR 反推](notes/ipv4-subnetting-practice-02.md)：完成 /28 网段计算、根据 50 台和 100 台主机需求选择前缀，以及将 /24 划分为 /26 的综合计算。练习中纠正了网络地址与可用地址、单个子网与整体网络容量、子网数量公式等易错点。本次为理论计算练习，没有新增 Ubuntu/VMware 实验验证。

2026-11-16 已完成 VLSM 入门实战：以 192.168.168.0/24 为地址块，按主机需求从大到小为四个部门分配子网。A 部门 60 台使用 /26（.0–.63），B 部门 28 台使用 /27（.64–.95），C 部门 12 台使用 /28（.96–.111），D 部门 5 台使用 /29（.112–.119）。四个子网共占用 120 个地址，剩余 136 个未分配地址（.120–.255）。本次为理论计算练习，没有新增设备配置或实验验证；下一次通过综合 VLSM 题继续巩固连续地址分配、子网边界判断和剩余地址计算，完成后再整理独立笔记。


2026-11-17 已完成 [VLSM 可变长子网掩码综合实战](notes/vlsm-practice-2026-11-17.md)：以 `192.168.168.0/24` 为地址块，按 100、50、25、12、5 台主机需求依次分配 A–E 五个部门，分别使用 `/25`、`/26`、`/27`、`/28`、`/29`。五个子网连续且无重叠，共占用 248 个地址，剩余 `.248–.255` 共 8 个地址，恰好还能组成一个可用主机数为 6 的 `/29` 子网。本次练习纠正了将 `/24` 总地址数误认为 254、将剩余 8 个地址误算为 7 的问题，进一步明确总地址数、可用主机数和剩余地址数的区别。本次为理论计算练习，没有新增设备配置或抓包验证。下一步学习 ARP 与 MAC 地址，并继续通过变式题巩固 VLSM 剩余空间判断。

2026-11-18 已完成 [Wireshark ARP 地址解析协议实验](notes/wireshark-arp.md)：学习 ARP 的基本作用，理解 IPv4 地址与 MAC 地址之间的映射关系，分析 ARP Request 和 ARP Reply 的报文结构，并通过 Windows `arp -a` 命令查看本机 ARP 缓存表。本次实验完成了 ARP 基础抓包与缓存表查看，初步掌握 ARP 请求与应答过程。后续继续巩固 ARP 报文字段，以及本地通信和跨网段通信时的 MAC 地址解析区别。

2026-11-19 已完成 [eNSP 华为交换机 VLAN 划分与跨 VLAN 通信](notes/ensp-vlan-inter-vlan-routing.md)：使用两台华为 S5700 交换机和四台 PC，完成 VLAN 10、VLAN 20 划分，配置 Access 接口、Trunk 链路及 VLANIF 三层网关。通过五项通信测试，验证了同 VLAN 跨交换机通信和不同 VLAN 之间的通信。本次实验核心配置与通信验证已完成，SW1、SW2 配置均已保存；Wireshark 802.1Q 抓包尚未进行。

## 学习节奏

- 每次学习控制在 30～45 分钟。
- 每次尽量完成“理论、操作、验证、练习、总结”五个环节；纯理论练习应如实标注，不虚构实验验证。
- 每周至少整理两篇真实学习记录。
- 实验状态只根据实际操作结果更新。
- 每完成一个阶段，在 README 和对应学习文档中记录成果。
